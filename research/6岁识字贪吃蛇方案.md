# 6 岁识字贪吃蛇：玩法选型与首版方案

适用目标：6 周岁；主要练习汉字认读和汉字组词；可以加入拼音拼写；首版不安排英语单词。

## 推荐选择

采用经典单人、方格移动、关卡制的持续增长玩法。参考 Snake '97 的简单规则，配合 Snake.io 一类圆润、鲜艳的卡通美术。按用户 2026-10-21 的最新方向，头部使用炸弹迷宫已有的「小飞星」，身体由一节一字的汉字字块组成；不要求具有蛇的外形。保留自动前进、四方向转弯、吃字变长、避开自身队伍和规划路线的玩法。

与现有炸弹迷宫保持共同的学习结构：每关 5 个不同目标、逐题完成、错误内容后续再练、独立游戏进度。地图改成宽阔场地，首关不沿用炸弹迷宫的密集砖墙。

这是产品设计建议，尚未修改或实现学习系统代码。

## 候选玩法比较

| 参考方向 | 适配程度 | 判断依据 |
|---|---|---|
| 经典单人贪吃蛇 | 首选 | 规则少，文字能固定显示，速度与障碍可以独立调节，容易把“吃到正确汉字”变成游戏中的有效行为。 |
| Snake.io / slither.io 式竞技 | 借鉴形象、成长与食物反馈 | 自由转向、追逐和对手干扰会占用阅读注意力。首版可采用类似外观，玩法仍用单人四方向控制。 |
| Snakebird 式解谜 | 后续可选 | 适合空间规划，但重力、推块与身体支撑会增加另一层学习任务。更适合作为后续独立模式。 |
| SSSnaker 式弹幕战斗 | 首版不采用 | 同时躲弹幕、选技能和认字，任务叠加较多；识字容易变成战斗之间的附加步骤。 |
| Snake VS Block 式跑道 | 首版不采用 | 持续逼近的选择窗口适合快速反应，长文字与仔细辨认较难安排。 |

## 核心流程

每关选择 5 个不同目标字，逐题出题，不把五题和所有干扰项同时堆满地图。

1. 顶部给出当前任务，地图显示 2–3 个文字食物。
2. 孩子观察、听题，决定路线，再让小飞星出发。
3. 小飞星自动前进，孩子转弯，绕开错误选项和自己的汉字队伍。
4. 吃对：队伍尾部增加一节对应汉字，给出简短读音与反馈。小飞星体型保持稳定，增长由字块队伍表现。字块转弯时文字仍正向显示。
5. 吃错：进入短暂安全停顿，提示再听或再看一次，继续完成这道题；记录首次选择错误。
6. 五题完成后展示通关与本关练过的字。未独立答对的内容在后续关卡再出现。

练习模式默认新题出现时停在安全位置，孩子确认后继续移动；运行中随时可以暂停。熟悉后可开放连续移动挑战模式。这样把阅读时间和操作难度分开，也保留真正的贪吃蛇路线规划。

## 学习内容分三种模式

### 一、听音吃字：首版核心

示例：播放“山”，地图出现「山」「水」「木」，孩子吃「山」。

- 初期从 2 个选项开始，熟悉后变成 3 个。
- 默认音频提示，提供重听；显示拼音、图片属于额外提示。
- 尚不熟悉的字可先看字听音，再进入选择；这类提示练习与独立答对分开记录。
- 不把“提示显示山、再去吃山”的外形匹配直接算成独立认读。
- 对同音字、多音字使用组词或语境限定；不能仅凭相同读音设置一个正确、另一个错误。

### 二、看图组词：首版第二模式

示例：显示一幅正在喷发的火山图，任务为「火 □」，地图出现「山」「车」「门」。吃「山」后组合为「火山」，展示完整词并朗读。

- 第一阶段一次只补一个字，先用具体、常见的两字词。
- 相同规则也可用于「苹 □」配苹果图，再选「果」。
- 可以先固定前字补后字，再逐步加入固定后字补前字。
- 初期不要求把整个词的字都按顺序吃完，避免认词与顺序记忆同时增加。
- 组词必须有图片或语境限定。例如只给「火 □」，「火山」「火车」都成立，不能无条件只判一个正确。

### 三、拼音拼写：后续模式

若孩子已熟悉拼音，可以加入完整音节匹配，之后再安排按顺序吃拼音块。

示例：「马」→先吃「m」，再吃「ǎ」，组合为「mǎ」。第一阶段可先直接在「mǎ / mǐ / mā」中选择完整音节。

- 汉字认读与拼音拼写分开选模式，首关不混在同一题中。
- 把声调作为音节的一部分显示，组合完成后展示完整拼音。
- 逐题只显示当前要选择的部分，或明确标出顺序，避免一地散落字母造成搜索负担。
- 保留 zh/ch/sh、整体认读音节等教学单位，不能把所有音节机械拆成任意字符。

## 适合首版的游戏规则

| 项目 | 建议 |
|---|---|
| 场地 | 开阔、固定视角；地图规格由文字可读尺寸决定，首关不放复杂障碍。 |
| 移动 | 自动前进、四方向转弯；格子之间平滑移动，保持操作清晰。 |
| 速度 | 开局慢速，整关固定；吃字增长不自动加速。具体速度通过孩子试玩调整。 |
| 蛇长 | 开始短蛇，每次正确增加一节；五题一关限制增长，下一关恢复短蛇。 |
| 文字 | 高对比、大字，选项外观和大小一致，不用颜色暴露答案。 |
| 误吃 | 练习模式暂停、纠正、再试；保留已完成目标，首版不因认错一个字直接整局重来。 |
| 撞墙/撞身 | 与识字错误分开记录。练习模式允许本题安全重置；挑战模式以后再加入生命或连胜规则。 |
| 投放 | 正确选项与干扰项都可到达，不贴蛇头立即生成，也不要求穿过错误选项才能到达正确答案。 |
| 反馈 | 吃对有成长、星星和简短声音；读音播放期间暂停或保护现场，避免听音时被撞死。 |
| 控制 | 键盘方向键、手柄方向键/摇杆、触屏方向控制；保留清晰的开始、暂停和重听。 |

错误选项应当可以通过绕行避开。若被设计成不可避免的狭道堵口，孩子就可能因为地图而被判成“不会认字”。

## 难度如何推进

先增加学习难度，再单独增加游戏难度，避免同时加速、增加蛇长、增加干扰项和引入生字。

1. 两个选项、慢速、无障碍，熟悉听音吃字。
2. 三个选项，加入已学过的形近字或相近词。
3. 看图补全两字词。
4. 少量宽通道障碍，提高路线规划要求。
5. 自愿开启连续移动、拼音拼写等额外挑战。

题库优先使用已经接触、尚需巩固的内容。先用少量固定示例验证玩法；之后再连接学习系统中的汉字和词语来源。

## 与现有炸弹迷宫的衔接

已经只读核对「S02 炸弹迷宫模块」聊天、项目规则及相关代码。现有模块采用每关五个不同汉字、拼音找字/汉字找拼音、场内选择、独立保存，以及错误内容再练。

识字贪吃蛇可以沿用这些产品原则，单独设计移动、投放和组词规则。游戏进度与练习结果保存到独立模块，不自动把游戏通关写成汉字课程“已掌握”，不改写炸弹迷宫的进度。

建议记录：首次选择、是否使用提示、后续纠正，以及碰撞次数。提示后的正确和独立正确分开看；碰撞不算识字错误。

## 首版范围与试玩判断

先做听音吃字、看图组词、五目标关卡、短蛇固定慢速、成长奖励、暂停重听、错误再练和独立进度。拼音拼写、竞技对手、弹幕战斗与复杂道具后续再考虑。

试玩重点观察：孩子是否先辨认再规划路线，是否因为看题频繁碰撞，是否通过乱吃绕过辨认，以及能否在下一轮换位置、换干扰项后仍认出目标。连续两三关的表现比单纯通关时间更有参考价值。
