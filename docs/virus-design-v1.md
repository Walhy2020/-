# 病毒造型第一版

## 已确认的规则

- 吃病毒增加身体长度。
- 吃对汉字增加星星积分，身体不因吃字变长。
- 病毒分小、中、大三档，通过累计成长值达到门槛后增长一节。
- 本轮试玩默认：小 +1、中 +3、大 +5；10 点长一节，余数保留。数值可在游戏参数中修改并保存；吃对汉字星星积分 +1。

## 本次造型

对比图：[virus-concepts-v1.png](virus-concepts-v1.png)。从左到右：紫色圆孢子、橙色小团子、薄荷绿果冻。

推荐紫色圆孢子：紫色与金色星星身体、青色地图区分明确；八个短圆触角形成清楚的病毒轮廓；圆眼和小嘴适合当前儿童卡通风格。橙色较接近身体颜色，薄荷绿较接近地图颜色。

紫色圆孢子已接入游戏，以 36、52、72 单位区分小、中、大三档，旁边实时显示当前配置的成长值。透明精灵为 `assets/virus-purple-v1.png`，由原图裁切和缩放，未用程序绘制美术。脚本：`scripts/build-virus-assets.py`。

顶部成长条显示距离下一节的进度，星星积分独立显示。身体只显示星星，认对的汉字记录在侧栏认字小册。调整成长门槛时仅对尚未使用的点数结算，已有身体不缩短。重新开局清空本局奖励，保留配置。
